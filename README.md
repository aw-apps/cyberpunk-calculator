# 🔮 Cyberpunk 計算機

一款賽博龐克風格的計算機網頁應用，霍虹燈效果、酷炫動畫，讓每一次計算都充滿未來感。

## 功能特色

- ➕➖✖️➗ 四則運算
- 🔢 小數點支援
- ⌫ 退格鍵
- 🔄 清除功能 (C / AC)
- 💡 賽博龐克霍虹 UI
- 📱 RWD 響應式設計

## 開始使用

直接用瀏覽器開啟 `index.html`，或前往 GitHub Pages：

👉 https://aw-apps.github.io/cyberpunk-calculator/

## 技術棧

- HTML5
- CSS3 (霍虹效果 + 動畫)
- 原生 JavaScript
